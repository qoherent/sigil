# U6: source-faithful Design export and native compatibility

The core exporter now emits schema 2 for language 0.8.0. Components, owner-qualified Tags, Facets, group and inline introductions, selected imports, references, links, payloads, validity and completeness retain their original UTF-8 byte provenance. Original captured source and configuration text remain unchanged. Invalid UTF-8 prevents transport creation; structurally invalid but representable sources retain partial records and diagnostics.

Native consumers validate this transport, retain its structural records through source scope, preparation, bindings and Design worlds, and use Tags in catalogs. Imports do not manufacture runtime calls. Native reports use version 2 with explicit byte or implementation UTF-16 coordinates and captured SHA-256 source digests. Existing generic store history keys stay readable; incompatible format-1 projections remain stored and cannot become current evidence. The eqval behavior algebra is unchanged.

## Evidence

- Full core suite: 110 tests and 100 steps pass.
- Full native suite: 76 tests pass, including shared real-exporter fixtures, provider cycles, scope/binding parity, structure-only invalidation, partial input rejection, incompatible legacy store preservation and compilation without inferred calls.
- A strengthened native diagnostic test first failed because its implementation source digest was lost; it passes after preserving the supplied capture identity when the source is outside the Design capture.
- Core lint, native rustfmt, native clippy with all targets and warnings denied, and diff whitespace checks pass.
- All 53 independently reviewed designs export and pass native scope validation in their three workspace boundaries: 2,227 Facets, 341 Tags, 649 introductions, 378 references and 21 links. This uses isolated 0.8 captures; it does not claim root activation.
- Aggregate TypeScript checking still identifies CLI/LSP consumers assigned to U7–U9. Root version activation and full repository acceptance remain U10.
- All six excluded user WIP files retain their pre-work SHA-256 hashes. No reviewed Sigil design changed.
