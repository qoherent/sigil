# Egglog for Sigil claims and laws

Teach the egglog/datalog language this repository pins. Hosts inject this file first; the language lives in `references/`. No compiler, repository checkout, or network is required to read the bundled instruction.

For a design claims interpreter, read the [design dialect](references/dialect.md).
For a whole-file implementation interpreter, read only the
[code dialect](references/code-dialect.md); it uses prepared code guidance
without loading design-row instructions. The prepared request's guidance is the
binding row specification; this skill is language background, and
`sigil-understand` is the design-language authority.

For authoring or reviewing repo `.egg` laws, read the [language reference](references/language.md). Examples are in-bundle excerpts named to the law programs; do not follow checkout paths.

Do not emit rules, commands, schedules, or non-literal arguments in a claims artifact. Do not parse Turtle in egglog. Do not teach Sigil design language here.
